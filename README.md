## Setup

1) Install dependencies:

```bash
npm install
```

2) Create `.env` from the template:

```bash
copy .env.example .env
```

3) Set `GEMINI_API_KEY` in `.env`.

4) Start the server:

```bash
npm start
```

Then open: `http://localhost:3000`
